🔍 What is ZXH Panel?

ZXH Official is an advanced Facebook phishing & security testing panel designed for educational and research purposes. It allows security researchers to understand how phishing attacks work in real-time using Firebase-powered live logging.

⚡ Core Features

  • Stealth Phishing Mode: Undetectable phishing layer that mimics Facebook's official login page with high accuracy — including neumorphic UI design that looks completely legitimate.
  • Real-Time Firebase Logs: Captured credentials appear instantly in the admin dashboard via Firebase Realtime Database integration. No delay, no refresh needed.
  • Clone Page Technology: High-quality Facebook lookalike page with follower generator theme — victims believe they are getting free followers.
  • Campaign Generation: Generate unique phishing session links tied to your admin account. Each campaign is tracked separately.
  • Victim Logs & History: Complete history of all captured data including emails, passwords, follower counts, and timestamps.
  • Multi-Admin Support: Register multiple admin accounts with secure password hashing and recovery key system.

🛡️ Security & Encryption

  • Passwords are hashed using SHA-256 + custom salt before storage
  • Recovery key system for secure password resets
  • Session-based authentication with expiry
  • Firebase Realtime Database with restricted access rules

📊 How It Works

  • Step 1: Admin generates a unique campaign link from the dashboard
  • Step 2: Victim clicks the link and sees a "Facebook Followers Generator 2026" page
  • Step 3: Victim enters their Facebook credentials to "verify" their account
  • Step 4: Credentials are captured and displayed in real-time on the admin panel
